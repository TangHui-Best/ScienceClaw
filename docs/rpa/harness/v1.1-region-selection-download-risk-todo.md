# Harness v1.1 区域选择与下载动作风险待办

> 说明：这是 v1.1 待办风险清单，不是正式 Feature / Evidence artifact。进入实现前仍需创建或更新对应 Feature 与 Evidence。

## 背景

Harness v1 已经形成 capture -> review -> promote -> deterministic -> user-input replay -> full-live profile 的核心闭环，但区域选择和自然语言下载动作仍有若干能力风险需要在 v1.1 收敛。

本清单从两个已知缺口出发：

- 区域选择目前缺少真实 governed asset 覆盖，尤其缺少从真实选区进入 accepted trace、Skill 编译和 replay 的完整验收样本。
- 自然语言“点击列表第一行的名称”触发下载属于 action side effect，不应被误判成普通字段提取或表格提取。

## 现有依据

- `docs/features/F011-rpa-region-scoped-snapshot.md`：F011 仍为 active，已记录 selected-region evidence classification、action/download side effect、iframe fallback 等 hardening 链。
- `docs/evidence/EV-011-rpa-region-scoped-snapshot.md`：记录过 region-backed action/download 被错误编译成表格提取的回归，后续通过 compiler evidence gate 修复。
- `docs/evidence/EV-018-rpa-harness-v1-closeout-stabilization.md`：明确 bootstrap assets 不包含真实 region-selection captures，F018 只是 v1 review-ready，不代表真实内网/模型/区域选择全部覆盖。
- `docs/rpa/harness/usage-and-triage-guide.md`：F016 user-input replay 第一切片是 record-only boundary injection，不证明 live UI side effect。

## v1.1 推荐切片

第一切片建议聚焦 `V11-RD-003`，因为它同时覆盖区域选择、自然语言语义选择、动作副作用、下载信号、Skill 编译和 Harness 验收。

建议验收路径：

1. 构造 controlled HTML：列表或表格第一行名称可点击，并触发 Playwright download。
2. 录制自然语言步骤：“点击列表第一行的名称下载文件”。
3. 生成 expected signals：目标为 first row name，必须触发 download。
4. 跑 full-live / post-capture / compiler regression。
5. 报告中区分 Planner 选错行、Runtime 未捕获下载、trace 缺 download signal、compiler 误编译、fixture 不支持下载五类失败。

## 非目标

- 不开启 Harness v2。
- 不做自动 candidate / golden promotion。
- 不把 download 场景写成站点特例。
- 不把 iframe 修复混入普通区域选择优化；iframe 应先有独立可复现场景。
- 不用“空值不是成功”这类全局硬拦截替代具体 evidence / side-effect 验收。
